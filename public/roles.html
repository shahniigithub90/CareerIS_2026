User Roles & Permissions

Understand how different users interact with CareerIS based on their role and access levels

Three Core User Roles

Each role has specific permissions and responsibilities within the system

Student

Current university students

Primary Responsibilities
  • Search and apply for internships
  • Upload and manage certificates
  • Save favorite internship listings
  • Track application status
Key Features Access
  • Internship Listings & Search
  • Resume/CV Upload
  • One-Click Applications
  • Certificate Upload
  • Certificate Download
  • Post Jobs (Alumni)
  • Verify Certificates (Admin)
    • Internship & Certification Access

    Alumni

    Graduated students

    Primary Responsibilities
    • Post job opportunities for students
    • Manage alumni profile and directory
    • Organize batch reunions
    • Stay updated with university news
    Key Features Access
  • Profile Creation & Management
  • Alumni Directory Search
  • Job Posting for Students
  • Batch Reunion Organization
  • Certificate Download
  • Verify Certificates (Admin)
  • Apply for Internships
    • Alumni & Limited Certification Access

    Administrator

    University staff

    Primary Responsibilities
    • Verify uploaded certificates
    • Manage all user accounts
    • Monitor system activities
    • Post university news updates
    Key Features Access
  • Certificate Verification System
  • University News Updates
  • Certificate Management
  • Monitor Applications
  • Access All Directories
  • User Account Management
  • System Analytics & Reports
    • Full System Access

    Role Interactions & Workflow

    How different roles work together in the system

    Student

    Uses: Internship Search, Applications, Certificate Upload

    Alumni

    Uses: Job Posting, Directory Search, Reunion Organization

    Administrator

    Manages: Certificate Verification, News Updates, System Monitoring

    Typical Workflow Example

    1
    Alumni Action

    Alumni posts a software developer internship opportunity on the portal.

    2
    Student Action

    Student searches internships, finds the posting, uploads Python certificate, and applies.

    3
    Admin Action

    Admin verifies the student's certificate authenticity in the certification portal.

    Role Progression & Transition

    How users can move between roles over time

    Student Role

    Access to:
    Internship Portal (Full)
    Certification Portal (Upload/Download)

    Graduation + Admin Approval

    Upon graduation and admin verification, students can transition to alumni role

    Alumni Role

    Access to:
    Alumni Portal (Full)
    Certification Portal (Download Only)
    Internship Portal (Post Only)

    Important Notes
    • Students: Can upload/download certificates, apply for internships, search listings
    • Alumni: Can post jobs, search directory, organize reunions, download certificates
    • Admins: Can verify certificates, post news, manage all users and content
    • Role transitions require admin approval for security purposes
    • All role activities are logged for monitoring and analytics
